## Requirements

- Python 3.10 or later
- A Hugging Face account
- A Hugging Face API token with permission to call Inference Providers
- Access to a supported chat model through an enabled Inference Provider
- Available inference credits or another permitted provider arrangement

## Installation

1. Create and activate a Python virtual environment.
2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Create a `.env` file in the project directory and add your Hugging Face token:
   ```text
   HF_TOKEN=your_huggingface_token
   ``
4. Open `task.ipynb` in Jupyter Notebook or VS Code.
5. Run the notebook cells in order.
