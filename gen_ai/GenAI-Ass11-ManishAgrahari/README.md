## How to Run

Make sure Python and the required libraries are installed.

```bash
pip install pandas matplotlib numpy
```

Then run each task individually:

```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
python task6.py
python task7.py
```

## Notes

* Each task is implemented in a separate Python file.
* Matplotlib is used directly for visualization.
* Pandas is used for data loading, cleaning, and aggregation.
* NumPy is used where numerical positioning is required for bar charts.
