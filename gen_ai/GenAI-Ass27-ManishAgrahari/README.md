## Required Python Packages

Install the required packages:
    pip install langchain-core langchain-groq langchain-community streamlit python-dotenv

## Environment Setup

Create a `.env` file in the project directory and add your Groq API key:
    GROQ_API_KEY=your_groq_api_key
Replace the placeholder with your actual API key.

## How to Run the Project

1. Install Python and create a virtual environment.
2. Install the required packages.
3. Configure your Groq API key in the `.env` file.
4. Run task.ipynb for Task 1 to Task 5 and Task 7.
5. Run `streamlit run app.py` for Task 6.
