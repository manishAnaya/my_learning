## Project Description

The Conversational RAG Assistant is a chatbot that answers questions using information retrieved from a PDF document.

## Project Structure

    conversational_rag/
    |
    ├── app.py
    ├── task.ipynb
    ├── physical.pdf
    ├── README.md
    ├── requirements.txt
    ├── .env
    └── chroma_db/


## Required Python Packages

Install the required packages using:
    pip install -r requirements.txt


## Environment Setup

Create a .env file in the project directory.
Add your Groq API key:
    GROQ_API_KEY=your_groq_api_key_here
